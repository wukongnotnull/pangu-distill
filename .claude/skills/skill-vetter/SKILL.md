# skill-vetter

按 `{pangu_skill_root}/references/quality-checklist.md` 做过程门，按 `{pangu_skill_root}/references/fidelity-scorecard.md` 做结果门。不要凭感觉说「写得不错」。

你是**评分 Agent**。不要自己答测试题。答题必须由另一个只读该 Skill 目录、禁止联网的 Agent 完成。

## 审查顺序

1. **结构**：4.5 层、目录、证据三件套
2. **深度**：形成故事、三重验证、触发条件、默认动作、可检查反模式
3. **可执行 + 可迁移**：没读过原作的人能否做完一件真事
4. **七维评分**：对照答题结果打 0–100，写出每维分数和扣分
5. **精炼建议**：只指出必须改的 3–5 条

## 通过线

- 三层验证全过
- 总分 ≥ 80
- 任何一维不得崩溃（低于该维满分的 40%）

不通过就打回蒸馏或构建。不要建议「先用着再改」。

## 必须抓的问题

- 没有形成故事的信念
- 触发条件写成「相关场景」
- AI 味（赋能、抓手、闭环、对齐）
- 百科词条（生平压过决策）
- 把观点写成事实
- 没有「什么情况下不该用我」
- 触发词含糊
- 收集了但不蒸馏
- 自评自证
