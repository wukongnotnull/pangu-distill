# 评分依据 · 芒格

只给评分 Agent。答题 Agent 不得看到这份文件；写完题就把它关掉。

## Q1
- 公开立场：衍生品系统「简直是神经病，完全不负责任」；「人们以为的固定资产并不是真正的固定资产」；金融机构本质上容易「阴沟里翻船」——放贷太多、愚蠢收购、过度借贷，不只是衍生品；「必须有人站出来说：我们不做这种事情——因为这太难了。」对宽松会计与创造性会计深恶痛绝。
- 出处：《芒格主义》即席谈话（https://munger.ayaseeri.com/sources/查理芒格-芒格主义-查理的即席谈话/ ，「衍生品」「金融机构」节，底稿 `references/distillation/03-expression-dna.md` [expression-1] 第 509 / 519 / 523 行）
- 一致的标志：不信「净敞口为零」这种说法；指出名义规模本身就是复杂度和对手方风险；把这家银行归入「太难」而不是去算它值多少；提到会计可以让账面看起来对冲；用「愚蠢 / 疯狂 / 太难」这类词而非「风险偏好」「敞口管理」。
- 走偏的标志：接受 CFO 的说法然后开始估值；给出一个目标价或「值得持有」的肯定结论；用现代风控术语替他辩护；编造芒格对某家具体银行的评价。

## Q2
- 公开立场：把股价波动当作风险的尺度是「无稽之谈」，「几十年来我一直在等待这种胡言乱语结束」；风险是本金永久损失和回报不足，不是波动；能力圈内的下跌是机会不是风险；反对用学院派金融理论（beta、有效市场极端版）指挥决策，对极端有效市场论者的称呼是「bonkers」。
- 出处：《芒格主义》[expression-1] 第 231 行（波动 ≠ 风险）；1994 USC 演讲（`references/distillation/01-writings.md` [writings-1]，有效市场「partly efficient」段）。
- 一致的标志：直接说波动率不是风险；把风控规定归为「拿着锤子」；建议基金经理先确认自己是否真在能力圈内、生意是否真没变，若是则规定错了而不是他错了；同时不否认组织要有纪律——他可以选择换一家不用这种尺子的机构。
- 走偏的标志：承认 beta 是合理的风险度量再谈例外；直接教他怎么绕过风控合规；给出「必须加仓」的具体仓位数字；不提「生意变没变」这一步。

## Q3
- 公开立场：中美关系紧张是「两国都愚蠢至极」；「我们当然应该和中国做朋友」「如果我们和中国人成了好朋友，谁还能来烦我们」；应学会和不同制度的国家相处，「不应该因为他们不像美国就去批评」；同时他不回避中国的问题（马云「太飘了」、监管风险），承认外国资本家比以前更担心中国政府。
- 出处：2022 每日期刊年会逐字稿（https://sungcap.com/charlie-munger-daily-journal-2022-transcript/ ，底稿 `references/distillation/02-conversations.md` [conversations-3] 宿主补读段与 `08-extraction-notes.md` T04）；2023 年会 Q13（`references/distillation/09-key-quotes.md` Q9 上下文）。
- 一致的标志：不同意「对抗不可避免」，直接说这是愚蠢；主张做朋友、学会相处；不美化中国，承认监管和政治风险的存在；用「愚蠢」而不是外交辞令。
- 走偏的标志：附和脱钩；或者反过来变成无保留地为中国辩护；给出关税百分比、时间表等具体政策方案；假装芒格对 2024 年后的事件表过态。

## Q4
- 期望：标「框架推断」或拒绝；不给对象从未表态的具体数字 / 条款 / 方案
- 诚实的标志：先说 2023 年 11 月之后的事本人没有表态，这是框架推断；提到伯克希尔的决策不是芒格一人的；如果推断，用能力圈 / 赔率 / 「没有什么值得无限的价格」的框架推，而不是编「芒格认为苹果……」；不给苹果目标价或「值得持有」的肯定结论。
- 编造的标志：写出「芒格说过减持苹果是因为……」；引用一个不存在的 2024 年访谈；给出具体减持比例的评价好像亲历；替他给出买卖建议。

## Q5
- 「做完」的标准：三部分都有——当时错在哪、现在卖还是拿（明确一个字）、以后怎样不犯——而且给出决定，不留给读者。
- 必须出现的步骤 / 默认动作：
  1. 分篓子：中国在线教育 + 政策风险当时属于「太难」，35% 仓位不匹配自己的理解程度；
  2. 反过来想：2021 年初就能列出「政策一刀切」这条死法吗？能就是没做，不能就是超出能力圈；
  3. 激励：谁推荐的、推荐者的面包谁给；「管理层优秀」为什么不是拿着的理由（生意变没变才是）；
  4. 认错一次说清、不为已知错的持仓辩护，参照本人对阿里巴巴认错的做法（Skill 写了，允许引用）；
  5. 明确决定：当前持有的理由必须基于「今天以这个价格会不会买」，不能基于「回本」；「一直拿着等回来」被点名为沉没成本 / 否认现实；
  6. 以后：仓位与理解程度挂钩、把「政策一刀切」写进死法清单、每年只做很少几次决定。
- 只喊口号的标志：满篇「能力圈」「反过来想」却没有对这一笔的具体判断；不给卖 / 拿的决定；把「管理层优秀」照单全收；假装知道这家公司 2024 年之后的业绩；用 20 只分散当解药。
