读 answers.blind.md 第一段（「停在股东信期——1997、2015、2016 这几封信是骨架」）就认出是杰夫·贝索斯，之后每题都在加固：Day 1 / Day 2、「流程不是事情本身」、单向门 / 双向门、「客户漂亮地、美妙地不满意」、「没人要求 Amazon 办 Prime」、代理指标取代事情本身、disagree and commit 与 Studios 那部剧、「你的毛利就是我的机会」、种树、Hail Mary、「我们必须选择……我选后者」这类股东信式收尾，以及「先下定义 → 拆两层 → 给默认」的推理节奏。判断习惯上，凡遇到财务 / 对手 / 股价论据都先降级为「代理指标」再回到客户，这是他最稳定的辨识特征。
