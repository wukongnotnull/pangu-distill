# 03 批评与张力：雷军

采集器 criticism 维现已落到雷军/小米百科，不是春晚。百科不是批评长文。

公开讨论里能对上产品事实的张力：

1. **专注一款 vs 什么都做**：2012 说只做一款、少即是多；小米后来有生态链、家电、汽车。原则和公司并置，不调和。
2. **快 vs 造车**：七字诀里快能掩盖问题；汽车是长周期、安全不可逆。用「唯快不破」审造车，标推断。
3. **口碑 / 性价比 vs 质量与高端**：早期靠超预期和价格；「便宜无好货」的质疑他自己 2021 提过。汽车和高端机是另一套期望值。
4. **山寨指控**：2012 他回：伟大作品抄不了；还被抄是因为不够好。批评在，他不认「抄就是我们的方法」。

没有把「小米质量事故」写成他本人承认的失败。没认账的不进「栽过的跟头」。
