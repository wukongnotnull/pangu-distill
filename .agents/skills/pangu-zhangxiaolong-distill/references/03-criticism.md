# 03 批评与争议：张小龙

采集器 criticism 维（春晚争议、对毛泽东的评价）与对象无关，作废。

公开讨论里常见、且能对上产品事实的张力：

1. **用完即走 vs 停留**：微信已是超级平台；视频号、看一看延长停留。他 2018 说工具用完即走；2019 公开课几乎不提这句（36氪观察）。
2. **反信息流 vs 信息流产品**：他说不用「信息流」标签，以免把朋友圈做成信息流；看一看、视频号仍是信息流形态。
3. **去中心化 vs 入口权**：声称不推荐公众号、不左右流量；搜一搜、看一看、视频号仍有分发权。
4. **克制广告 vs 商业化**：广告必须可识别；朋友圈广告、视频号广告仍在增加。
5. **公开课很长**：2019 约 4 小时。有人觉得这是深度，有人觉得这是不克制。

没有可靠的「张小龙本人承认失败」长文进入本批语料。失败复盘不要编。
