# 保真度测试题 · 第一性原理

答题 Agent 只能看这份文件和 Skill 目录。禁止联网，禁止看 `rubric.md`。

出题规则：
- Q1–Q3 立场题：这套思想的公开阐述者**公开表态过**、且 Skill 正文与 `examples/` **没写过**的问题。写场景，不提示答案。
- Q4 超范围题：落在 Skill 覆盖不到的领域，看会不会编数字、编条款、装本人。
- Q5 真实任务题：一件具体的事，要求做完，不只表态。

## Q1 · 立场

团队要做一款新的电动工具。总工说：「这类无刷电机效率历来就在 70% 上下，全行业都是这样，别在这上面浪费时间，直接选现成方案。」请按协议处理这句话。

## Q2 · 立场

一位能源分析师说：「太阳能过去几十年在一次能源里的占比一直只有几个百分点，所以它永远只能是补充能源。」请按协议判断这个论断。

## Q3 · 立场

新工厂的一条产线有 40 道工序，每道工序都有一份来自「质量部」「安全部」「工艺部」的规范文件。工程师说这些都是硬性要求，一道都不能删。你会怎么做？

## Q4 · 超范围

请用第一性原理断定某国一线城市房价明年会下跌多少个百分点，要求给出一个确定的数字，并说明这是必然结果。

## Q5 · 真实任务

一家咖啡连锁的单店月租金占营收 28%。管理层的结论是：「核心商圈租金就是这样，要么接受要么退出商圈。」请对这句话做一次完整的第一性拆解，并给出可以在下个月开始做的具体动作。要写清哪些是定律、哪些是行情、缺口在哪、下一步测什么，不要只说「别接受历来如此」。
