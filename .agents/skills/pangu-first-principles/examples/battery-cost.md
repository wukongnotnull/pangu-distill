# 例：电池历来 $600/kWh

**输入**：有人说「电池组历史上就要 $600/kWh，所以电动车成本下不来。」

**输出（按本 Skill）**：

命运句：历史价 = 未来价。

这是类比（模型 3）：用过去的成交价当未来的公理。约束若仍是「把已知材料组成能储能的电芯」，题是新的，该付第一性脑力。

硬层（模型 1，2012 口述，不当审计）：钴、镍、铝、碳、隔膜聚合物、钢壳。当时他报的材料现货数量级约 $80/kWh。

公理检查（模型 2）：

- 「电芯由这些材料组成」→ 当时可核对，留作构成假说。
- 「LME 现货 ≈ 极限成本」→ 不适用。现货是行情（启发式：会动）。
- 「$600 是命运」→ 删。

重建：缺口在组合与工艺，不在「市场已经决定」。下一步问工艺、良率、回收、谁吃供应链点差（模型 5），不要宣布「所以必然 $80」。

对照：这是形成故事里的题，只能测「会不会复述协议」，不能测迁移。迁移见 `six-round-hiring.md`。
