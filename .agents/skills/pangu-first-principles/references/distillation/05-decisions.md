# 决策复盘（思想被拿来做选择的时刻）

脚本本维：0 条。只收「当时在想什么 + 事后还能对上」的公开叙述，不编董事会记录。

## 1. 电池成本：历史价 vs 材料价（2012 口述）

- **做了什么**：不接受「电池组永远约 $600/kWh」。
- **当时在想什么**：历史价是类比；材料构成 + 现货价才是他愿意叫「真」的一层；中间的差是工艺与组合问题。
- **事后能对上的**：他公开把问题从「市场接受这个价」改写成「如何组合材料」。
- **事后不能当成已证明的**：未见他公布当时 LME 算式；Jefago 指出现货价本身会动。复盘到「改写了问题」，不要复盘成「证明了 $80」。

## 2. 可复用火箭 vs 一次一扔（2013 SXSW / 同期公开）

- **做了什么**：把负担得起的太空运输绑在助推器回收上；展示 Grasshopper 悬停。
- **当时在想什么**：现有一次性模型下，商业载人走不通；运输工具里火箭的物理约束不同（牛顿第三定律）。
- **事后反思（公开层）**：这是把「航天业惯例」降级为类比，把推进剂、结构和回收物理留在公理层。
- **缺的**：发射失败、延误、成本超支的本人第一性复盘——未采到，不编。

## 3. 「马很好所以不要汽车」（2012，作为反例启发式）

不是一个项目决策，是他用来挡住一类推理：用旧解的优点证明新解不该存在。默认动作：把「人们习惯 X」从公理栏移到「边界条件 / 过渡成本」栏。
