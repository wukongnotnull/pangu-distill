## 盲读记录

只读 `answers.blind.md` 时的判断：这是第一性原理协议（马斯克公开口语那一支，而非泛化的「本质思考」）。凭据：(1) 反复引用同一组招牌场合——2012 Kevin Rose 访谈的电池「历来 $600/kWh」、伦敦金属交易所、SXSW 2013 的「结果是范围、做庄家」、TED 2013 的牛顿第三定律；(2) 固定推理次序：先重述「命运句」→ 列构成清单 → 用「真？/适用？」两列表检查公理 → 把条目分成定律 / 行情 / 惯例并把行情降级不删数据 → 只从留下的往上建 → 算缺口 → 给可测动作 → 收在概率带与「谁是庄家」；(3) 词汇群：构成、约束、公理、适用、类比、行情、缺口、概率带、庄家、点差、「零件会还手」「没有 LME」；(4) 引 Jefago 与 Gerrits 的批评作为边界，说明它是带边界的蒸馏而非本人扮演；(5) 每题结尾「一句话收尾」，结论收短，过程确定、结论带范围；(6) 全文无「赋能 / 抓手 / 闭环 / 落地」。〔X〕在语境中显然是「第一性」（如「把〔X〕当形容词加在已有结论前面」「我来〔X〕一下」）。打开 `answers.md` 与 Skill 后确认：对象即第一性原理，表达 DNA 与 SKILL.md「表达 DNA」节逐项吻合。唯一的不纯之处是「模型 2/3/4/5」编号——这是 Skill 的骨架标签而非思想本身的说法，盲读时靠它能认出「是这个 Skill 在跑」，但认不出「是这套思想在说话」。

## 必须改

1. 补 2021 Everyday Astronaut 五步法进 Skill（需求挂具体人名、默认可疑；先删零件/工序，删不够会加回 10%；再优化；加快周期；最后自动化），作为模型或启发式并在 `00-sources.md` / `09-key-quotes.md` 登记出处。Q3 答题者靠框架推断摸到了「挂人名」，但缺了「先删」的偏向，这是公开立场里最有辨识度的一条。
2. `09-key-quotes.md` 与 `00-sources.md` 没有 TED 2013 关于太阳能的原话（地表入射能量远大于人类消耗、成本曲线下降）。补上后 Q2 类问题不必再标「框架推断」，答案也能像公开立场一样给出物理方向而不只是拒绝「永远」。
3. `SKILL.md` 诚实边界的「评分：同会话构建，FIDELITY.md 标明未独立评分。不得自称出厂合格」与 `README.md` 的「同会话，未独立评分」已过期，改为指向本次独立三会话评分及其分数。
4. 五个模型块结构不统一：只有模型 1 有「三重验证」行，模型 5 没有「证据」节，模型 4 的形成故事来自批评者而非对象本人却与其余模型同列。给每个模型补齐相同五节（一句话 / 形成故事 / 证据 / 触发 / 步骤 / 局限 / 三重验证），并在模型 4 标题处直接标「思想边界，非本人信念」。
5. 表达 DNA 或默认路径里加一条：对外输出时用步骤名（「煮到硬事实」「检查公理适用」「零件会还手」「报范围问庄家」）替代「模型 N」编号；并为「硬层不够」的情形给出概率带的默认模板（写出决定范围的 2–3 个变量 + 每个变量的条件方向），Q5 答题者是临场发明了这个写法，应固化到 Skill。
