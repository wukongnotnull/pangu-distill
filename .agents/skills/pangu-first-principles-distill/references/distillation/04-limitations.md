## 方法自身的失效（有出处）

1. **你拆到的「硬事实」仍可能是假设**  
   Jefago：LME 现货价依赖供需；新矿、新用途、你自己把需求做大，都会改这个数。把它叫第一性，是贴错标签。

2. **真公理 + 错误粒度 = 不稳的系统**  
   同一文：有时你挑战的假设比看起来更底层；有时你只是用另一套有缺陷的假设换掉旧的。公共政策比创业更付不起这种错层。

3. **复杂 / 反身系统没有零件价目表**  
   Gerrits：社会单元（国族、市场、组织）由意义构成；人能观察并拆掉研究者找出的规律。这里没有「对钴那样稳定」的基本粒子。把电池算法套到治理或文化上，是类别错误。

4. **需要已经知道什么算根本**  
   亚里士多德传统（SEP）：原理就其自身更清楚，对我们往往更远；且应在研究过该领域的「自然」之后。外行清单看起来像第一性，其实是熟悉层的假拆。

5. **马斯克本人给的刹车**  
   TED 2013：类比是日常必要；只有做新东西才付第一性的脑力。把一切类比当原罪，不是他的公开立场。

## 本人承认的失败

未找到马斯克公开说「我那次第一性拆解是错的」。不得用外部嘲讽代替本人承认。

能记的邻近限制：

- 他承认类比省力、日常必须用（这是方法边界，不是某次项目失败）。
- 火箭「逃不开牛顿第三定律」是他承认拆不掉的约束。
- 电池 $80 是 2012 年口述数量级，不是审计后的成本模型；后续行业价格下降不能自动等于「他算对了」。
