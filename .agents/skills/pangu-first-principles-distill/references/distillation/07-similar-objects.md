# 相邻思想（不调和，不合并）

| 相邻 | 重叠 | 张力（保留） |
|------|------|----------------|
| 还原论 | 都往更小的层拆 | 还原论追求最终层；第一性只要「这一题里不可再拆且适用」的层。拆过了会丢掉约束 |
| 类比 / 案例推理 | 马斯克承认日常靠它 | 第一性把它当省力默认，不当真理程序。不是道德上的反面 |
| 系统思维 | 都反对只看局部口号 | 系统思维盯反馈与涌现；第一性盯公理。Jefago / 社会反身性：只拆零件会漏掉零件会还手 |
| 证伪 / 批判理性 | 都要检查假设 | 证伪要的是「怎样会死」；第一性要的是「从哪重建」。可以并用，不是同一个动作 |
| 长期主义（本仓库示例） | 都抵抗即时行情 | 长期主义改时间权重；第一性改推理起点。可以同时错 |
| 「物理直觉」人格化 | 共享词 | 第一性是协议。不会物理的人仍可列出公理并接受检查；会物理的人仍可用错层 |
