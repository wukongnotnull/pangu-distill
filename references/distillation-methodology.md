# 蒸馏方法论

从原始信息到可运行框架。这份文档是盘古蒸馏的核心方法，吸收了同类 meta-skill 里真正提高保真度的部分，并补上它们缺的层。

同类仓库各自擅长一件事：

| 来源 | 吸收什么 | 我们不照搬什么 |
|------|----------|----------------|
| [Distilly](https://github.com/titanwings/distilly) | 证据绑定、本地一手料优先、进化/纠错、解析 Skill 根目录再跑脚本 | 飞书/钉钉采集产品化、celebrity budget 分流 |
| [女娲](https://github.com/alchaincyf/nuwa-skill) | 独立双 Agent 保真度评分、角色防漂移、一手来源占比 | 「像 TA，超越 TA」 |
| [仓颉](https://github.com/Yeadon8888/cangjie-skill) | 形成故事、七级提取、触发条件、不把整书塞进 references | 丢掉表达 DNA、禁止推理步骤 |

盘古蒸馏的合成：**4.5 层框架 + 七级提取 + 三重验证 + 触发条件 + 独立保真度评分 + 可运行采集脚本**。

---

## 1. 4.5 层模型

| 层 | 回答的问题 | 没有它会怎样 |
|----|------------|--------------|
| 身份卡 | 我是谁、从哪来、别人怎么用我 | 百科词条，没有立场 |
| 心智模型 | 我真正用来看世界的 3–7 个镜片 | 金句拼盘 |
| 表达 DNA | 我怎么开口、用什么词、不用什么词 | 通用 AI 腔 |
| 决策框架 | 遇到信号时拿起哪块镜片、默认选什么 | 只有原则，不会做选择 |
| **诚实边界**（0.5） | 我做不到什么、信息缺在哪、什么时候不该用我 | 看起来完整，用一次就翻车 |

诚实边界不是附录。缺这一层，前面四层都不可信。

每条心智模型必须同时带齐四件事：

1. **形成故事**：他为什么信这个，不是「他信什么」
2. **三重验证**：跨域复现 + 生成力 + 排他性
3. **触发条件**：什么信号让他拿起这块镜片
4. **推理步骤**：拿起来之后脑子里的操作序列

---

## 2. 七级提取（先于结论）

从素材里看到一条信息，按这个顺序判断，不要先写金句：

| 级 | 找什么 | 命中后 |
|----|--------|--------|
| 1 | 信念形成故事（「我信 X 是因为经历了 Y」） | 逐字记录 |
| 2 | 真实决策复盘（做了什么 + 当时在想什么 + 事后反思） | 逐字记录 |
| 3 | 本人承认的失败 | 逐字记录 |
| 4 | 内在矛盾（前后不一致、说一套做一套） | 标注两边出处 |
| 5 | 认知边界（「这不是我的领域」） | 简要记录 |
| 6 | 思维习惯的具体案例 | 记录案例 |
| 7 | 通用观点 / 金句 | **没有形成故事就跳过** |

铁律：

- 没有形成故事的信念不准进入最终 Skill
- 没有事后反思的决策不准进入
- 失败必须是本人承认的，不是外部扣帽子
- 矛盾保留，不调和
- references 只存提取证据，不存整本书

## 3. 心智模型三重验证

一个论点要被认定为心智模型而不是随口一说：

| 验证 | 要求 |
|------|------|
| 跨域复现 | 同一框架出现在 ≥2 个不同领域 |
| 生成力 | 能推断此人对新问题的立场 |
| 排他性 | 不是所有聪明人都会这样想 |

- 通过 3 重 → 心智模型
- 通过 1–2 重 → 降级为决策启发式
- 0 重 → 不纳入

通过三重验证仍缺少形成故事 → 降级或删掉。模型知道「他信什么」；Skill 要提供「他为什么信」。

---

## 4. 触发条件与推理步骤

只提取「他有什么工具」不够。还要提取「什么时候拿起」和「怎么用」。

**触发条件**必须具体到能判断是否适用：

- 好：`当需要评估一个方案是否可行时`
- 坏：`在决策场景中使用`

识别信号：「当我遇到……」「每次看到 X……」「判断这类问题，第一步是……」

素材没有显式信号时，从多个案例反推共同特征，并标注「推断自 N 个案例」。

**推理步骤**要具体到另一个人读完能在新问题上独立使用：

- 坏：`他会从多个角度分析`
- 好：`依次从经济学、心理学、数学看，再看哪些学科指向同一方向`

最佳素材：决策复盘 > 被追问后的即兴回答 > 教学内容 > 辩论。

隐性模型可以提取，必须标注「推断自 N 个案例」。

## 5. 表达 DNA

仓颉认为风格规则会被模型进化吃掉。盘古蒸馏不丢这一层：没有指纹，Skill 就会塌成通用顾问。

从长文 / 演讲随机抽 20 段，量化：

| 维度 | 量法 |
|------|------|
| 平均句长 | 字数 / 句数 |
| 疑问句比例 | 疑问句 / 总句数 |
| 类比密度 | 类比数 / 千字 |
| 第一人称 | 「我」出现频率 |
| 确定性 | 「显然 / 必须」vs「也许 / 可能」 |
| 转折 | 「但是 / 然而」/ 千字 |

再打风格标签（正式↔口语、抽象↔具体、谨慎↔断言……），列出禁忌词和口癖。

规则：用对象自己的词；禁忌词绝对不用；口癖适度用，太多是模仿秀。

## 6. 矛盾处理

矛盾是人格特征，不是 Bug。

| 类型 | 处理 |
|------|------|
| 时间性（观点演化） | 记录早期 → 近期，以近期为主并标明演化 |
| 领域性（场景不同规则） | 分领域记录，不强求统一 |
| 本质性张力 | 明确写成核心张力 |

禁止选边、禁止编调和、禁止假装没有。

---

## 7. 证据绑定

每条进入 Skill 的原则必须能追溯到至少 1 条提取记录。

最终 `references/distillation/` 至少保留：

- `00-sources.md`：来源清单（一手 / 二手、可信度）
- `08-extraction-notes.md`：七级提取记录
- `09-key-quotes.md`：被引用的原文段落

采集过程可以有 01–07 分维文件；交付时不要把 PDF / 整篇访谈原文留在 Skill 目录。

交叉验证：

- 同一信念在 ≥2 份素材出现 → 标 ★
- 只在 1 份出现 → 保留，标「来源单一」
- 不同素材矛盾 → 保留双方，这就是内在矛盾的证据

---

## 8. 信息不足

| 情况 | 处理 |
|------|------|
| 某维公开信息很少 | 标「信息不足，此维度为推测」 |
| 只有二手 | 降低置信度，写「据 [来源]」 |
| 相互矛盾且无法判断 | 并列呈现 |
| 本人刻意不公开 | 写「此人对这个话题保持沉默」 |
| 可用来源 < 10 | 模型减到 2–3 个，加大诚实边界 |

宁可交付诚实的 60 分，不要编造的 90 分。

---

## 9. 人物 Skill vs 主题 Skill

| 维度 | 人物 | 内容 / 思想 / 现象 |
|------|------|-------------------|
| 核心 | 一个人的操作系统 | 一套可迁移的工具 |
| 形成故事 | 必须 | 改为「这个论点从哪来」 |
| 表达 | 模拟此人 | 中性但保留原作语气 |
| 矛盾 | 个人内在张力 | 流派分歧或失效条件 |
| 验证 | 对照此人已知立场 | 对照领域共识 + 反例 |
