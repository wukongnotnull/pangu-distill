# 素材整理指南

当 SKILL.md 进入采集和提取时读这份文档。

## 原则：references 存证据，不存原文库

```
❌ 把整本书 / 整篇访谈塞进 references
❌ references 下面什么都没有
✅ 来源清单 + 提取记录 + 关键原文
```

原始 PDF / EPUB / 录音只在提取过程中使用，不进入最终 Skill 目录。

---

## 采集文件

```
.claude/skills/pangu-[对象]-distill/references/distillation/
├── 00-sources.md              # 来源清单（必须）
├── 01-writings.md             # 著作 / 长文
├── 02-conversations.md        # 访谈 / 播客
├── 03-expression-dna.md       # 社交媒体 / 表达
├── 04-limitations.md          # 外部评价 / 局限
├── 05-decisions.md            # 重大决策
├── 06-timeline.md             # 时间线
├── 07-similar-objects.md      # 同类
├── 08-extraction-notes.md     # 七级提取记录（必须）
└── 09-key-quotes.md           # 关键原文（必须）
```

自我蒸馏或用户上传一手料时，另建 `01-source-[素材名].md` 作为提取底稿，仍不要把全书拷进去。

## 六路采集 + 一手料

| 路 | 文件 | 最低要求 | 停止条件 |
|----|------|----------|----------|
| 著作 | `01-writings.md` | ≥2 篇长文或 1 本书核心 | 核心论点开始重复 |
| 访谈 | `02-conversations.md` | ≥1 段深度对话 | 找到被追问后的立场变化 |
| 表达 | `03-expression-dna.md` | ≥20 条发言 | 风格可辨认 |
| 外部 | `04-limitations.md` | ≥2 个不同视角 | 正负评价都有 |
| 决策 | `05-decisions.md` | ≥2 个决策 + 反思 | 每个都有背景和事后看法 |
| 时间线 / 同类 | `06` + `07` | 关键转折完整 | 从成名前到最近 |

**一手资料优先于这六路。** 用户给了书、访谈逐字稿、聊天记录、笔记：先读这些，网搜只补缺口。

必须跑仓库脚本，不要只靠模型记忆：

```bash
# 从本仓库 scripts/ 解析绝对路径后再执行，不要假设 cwd 就是 Skill 根目录
python3 "{pangu_skill_root}/scripts/run.py" collect "[对象]" -o "[skill目录]/references/distillation/"
python3 "{pangu_skill_root}/scripts/run.py" team "[对象]" -a 7 -o "[skill目录]/references/distillation/"
```

用户给了本地文件：

```bash
python3 "{pangu_skill_root}/scripts/run.py" collect-local "[文件或URL...]" -o "[skill目录]/references/distillation/"
```

音视频：

```bash
python3 "{pangu_skill_root}/scripts/run.py" transcribe "[YouTube或本地音频]" -o "[skill目录]/references/distillation/"
```

脚本失败 → 写入缺口，不要装成已经采集。

## 来源优先级与黑名单

一手（本人著作 / 发言）> 权威媒体采访 > 社交媒体 > 二手转述。

**永远不作为来源**：知乎、微信公众号、百度百科。

每条信息标注：URL 或文件路径、一手 / 二手 / 推断、可信度（高 / 中 / 低）。

中国人物优先中文一手源：B 站、小宇宙、权威媒体、本人公号原文（公号可作一手，洗稿号仍在黑名单）。

## 分块扫描

### 书 / 长文（>1 万字）

1. 先读目录，标出最可能有形成故事、决策复盘、失败承认的章节
2. 这些章节精读，边读边按七级清单标记
3. 其余章节快扫，只提取命中 1–4 级的内容
4. 对话体著作：对立角色的反驳往往暴露边界和矛盾

### 访谈 / 播客

1. 即兴问答 > 准备好的演讲
2. 「我以前觉得……但后来……」是最高价值
3. 拒绝回答本身就是认知边界

### 社交媒体 / 短文

1. 争议性发言 > 日常分享
2. 删帖 / 修改 / 道歉 = 自我修正证据
3. 公开辩论 = 思维习惯的现场

### 聊天记录（自我蒸馏 / 蒸馏对话）

1. 看反复出现的判断，不要看一次情绪
2. 口头信念和实际选择冲突时，以选择为准
3. 用户的自我总结只是假说，要用记录证伪

## 提取记录格式

```markdown
# [维度] 调研记录

## 来源清单
| 来源 | 类型 | 可信度 |
|------|------|--------|
| [标题/链接] | 一手/二手 | 高/中/低 |

## 提取记录

### [编号] [标题]
- **优先级**：1-7
- **原文**：「……」
- **出处**：[章节 / 时间戳 / 链接]
- **类型**：信念形成 / 决策复盘 / 失败承认 / 内在矛盾 / 认知边界 / 思维习惯 / 通用观点
- **内容**：[提取到了什么]
- **交叉**：★ / 来源单一 / 与 [编号] 矛盾
```

`08-extraction-notes.md` 汇总全部高价值条目。`00-sources.md` 只列来源，不写长分析。

---

## 采集质量自检

- [ ] 六路都有文件，空的维度写明「信息不足」
- [ ] 一手来源占比 > 50%，否则加大诚实边界
- [ ] 每条提取有优先级和出处
- [ ] 1–4 级记录 ≥ 10 条
- [ ] 失败和矛盾没有漏（这两项最容易被成功叙事吃掉）
- [ ] 脚本跑过，或失败原因已写进 `00-sources.md`
- [ ] 没有整书 / 整篇访谈原文留在目录里
