# 输出规格

盘古蒸馏的产物必须同时满足：**可安装、可阅读、可执行、可验证**。

## 1. 目录结构（必须）

```
.claude/skills/pangu-[对象]-distill/
├── SKILL.md          # 主技能文件（必填）
├── README.md         # 使用说明（必填）
├── FIDELITY.md       # 独立评分卡（验证后必填）
├── references/
│   └── distillation/ # 00-sources / 08-extraction-notes / 09-key-quotes（必填）
├── examples/         # 输入 → 输出（至少 1 个）
├── scripts/          # 只放真正可运行的脚本
└── assets/
```

## 2. SKILL.md 头部（必须）

```yaml
---
name: pangu-[对象]-distill
description: 一句话说明何时触发、能解决什么。包含触发词。
---
```

约束：

- `name` 必须是 `pangu-[对象]-distill`，全小写，连字符分隔
- `description` 必须包含触发场景，不能只写「某某的方法论」
- 不要在 YAML 里塞长文

## 3. SKILL.md 正文结构（必须）

按顺序：

1. 标题 + 一句话定位
2. 身份卡
3. 心智模型（形成故事 + 触发条件 + 推理步骤）
4. 表达 DNA
5. 决策框架
6. 诚实边界
7. 工作流 / 使用方式
8. 验证清单
9. 资源引用（指向 `references/`）

人物技能还必须有「什么情况下不该用我」。
自我技能还必须有「口头信念 vs 实际选择」。

## 4. 分层披露（必须）

| 层级 | 放哪里 | 内容 |
|------|--------|------|
| 入口 | `SKILL.md` | 身份、原则、决策、边界、工作流 |
| 细节 | `references/` | 完整方法论、来源、案例拆解 |
| 样例 | `examples/` | 输入 → 输出，至少 1 个 |
| 工具 | `scripts/` | 只放真正可运行的脚本 |

`SKILL.md` 控制在约 500 行以内。细节进 `references/`。

## 5. 可读性约束

- 用对象自己的词，不用「赋能」「闭环」「抓手」
- 原则必须带「为什么」
- 决策节点必须带默认选择
- 反模式必须可检查（能判断有没有踩）
- 禁止只有口号没有步骤

## 6. 验证门槛

发布前必须通过：

- 结构完整性（4.5 层 + 目录 + 证据三件套）
- 深度门槛（`quality-checklist.md` 三层过程检查）
- 独立保真度评分 ≥ 80（`fidelity-scorecard.md`，禁止自评）
- 至少 1 个可运行例子

不通过就回去精炼，不要先装再补。
