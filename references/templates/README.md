# Skill 模板索引

## 模板目录

| 类型 | 模板文件 | 适用场景 |
|------|---------|---------|
| D1 人物类 | [person-skill-template.md](person-skill-template.md) | 蒸馏人物思维框架 |
| D2 内容类 | [content-skill-template.md](content-skill-template.md) | 蒸馏书籍/课程/影视 |
| D3 思想类 | [idea-skill-template.md](idea-skill-template.md) | 蒸馏理论/观念/范式 |
| D4 现象类 | [phenomenon-skill-template.md](phenomenon-skill-template.md) | 蒸馏商业/社会/组织现象 |

## 模板选择指南

```
用户输入是什么类型？
├── 人物（芒格、巴菲特、马斯克）→ person-skill-template.md
├── 内容（《反脆弱》、《原则》、TED课程）→ content-skill-template.md
├── 思想（长期主义、第一性原理、杠铃策略）→ idea-skill-template.md
└── 现象（瑞幸咖啡增长、内卷、躺平）→ phenomenon-skill-template.md
```

## 使用方法

1. 根据对象类型选择对应模板
2. 在 `references/templates/` 目录下查看模板详情
3. 复制模板内容到目标 Skill 目录的 `SKILL.md`
4. 根据模板结构填充内容

## 模板预览

### D1 人物类核心字段

- 角色扮演规则
- 身份卡
- 核心心智模型（3-7个）
- 决策启发式（5-10条）
- 表达DNA

### D2 内容类核心字段

- 核心论点（3-5个）
- 论证结构
- 表达风格
- 应用边界

### D3 思想类核心字段

- 起源与背景
- 核心机制
- 适用条件
- 反例与边界

### D4 现象类核心字段

- 表面规律
- 底层机制
- 偶然性与必然性
- 边界条件
