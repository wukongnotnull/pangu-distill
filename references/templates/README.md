# 蒸馏模板

选和对象匹配的模板，按 4.5 层模型填，不要把五个模板混成一锅。

| 模板 | 对象 | 核心产出 |
|------|------|----------|
| [人物](person-skill-template.md) | 一个人 | 决策框架 + 表达 DNA + 诚实边界 |
| [内容](content-skill-template.md) | 一本书 / 课程 / 文章 | 可迁移操作手册 |
| [思想](idea-skill-template.md) | 一个主义 / 理论 | 思想操作系统 + 误用边界 |
| [现象](phenomenon-skill-template.md) | 一个方法论 / 潮流 | 机制操作卡 + 失效条件 |
| [自我](self-skill-template.md) | 用户自己 | 真实决策系统，含自我欺骗 |

## 共同约束

1. 先填身份卡，再填心智模型，再填决策框架。不要倒过来先写金句。
2. 每个心智模型必须有形成故事、触发条件、推理步骤。
3. 每个原则必须带「为什么」和默认动作。
4. 诚实边界不能空。
5. 至少 1 个输入 → 输出例子。
6. 对外作答不带内部编号（「模型 N」「论点 N」「启发式 N」），用名字；引用 `09-key-quotes.md` 里没有的话标「记忆引用，底稿未收」。人物模板放在「角色协议」，其余模板放在「作答约定」或「工作流」。这两条改了要同步到已交付的样例——2026-09-10 曾因模板改了样例没跟，三轮评分都扣了同一处穿帮。
7. 过程门走 [`quality-checklist.md`](../quality-checklist.md)，出厂走 [`fidelity-scorecard.md`](../fidelity-scorecard.md)。
8. 目录和分层按 [`output-spec.md`](../output-spec.md)。
