## 1. 自我蒸馏

**触发：**「蒸馏我自己」「做一个我的操作系统」

公开渠道搜不到用户自己。必须要一手料：文章、日记、决策记录、视频、聊天导出。

流程：

1. 关掉纯网搜补人格。网搜最多用来核对用户提到的外部事实。
2. `collect-local` 读用户文件；没有文件就请用户粘贴。
3. 追问只用于补决策证据，不是做性格测试：
   - 「你最后悔的一次选择是什么？当时你在优化什么？」
   - 「你最被批评、且你心里部分同意的观点是什么？」
   - 「5 年前你信、现在不信的是什么？行为上改了吗？」
4. 口头信念和实际选择冲突时，以选择为准，把冲突写进诚实边界。
5. 用 [self-skill-template.md](templates/self-skill-template.md)。读起来必须像这个人，不能像「更优秀的我」。

## 2. 对话蒸馏

**触发：**「蒸馏这段对话」「从这些聊天记录做个 Skill」

1. 材料就是语料。不要用网搜给对话里的人补传记。
2. 提取反复出现的判断，忽略单次情绪。
3. 用户的自我总结只是假说，要用记录证伪。
4. 产出可以是 D5 自我，或「这段关系里的决策协议」。
5. 涉及第三人时脱敏，默认不公开。

---

## 3. 蒸馏对象已存在 Skill

1. 告知已有路径，问：加载 / 更新 / 另蒸一个聚焦维度。
2. 加载：直接用现有 `SKILL.md`。
3. 更新：走场景 7。
4. 不要静默覆盖。

---

## 4. 快速变化领域

AI / 科技 / 创业人物或现象：

1. 打「时间敏感」标签
2. 每个产出文件写采集时间
3. Skill 里写有效期（如 3 个月）
4. 建议按季度重蒸时间线和决策层

---

## 5. 批量蒸馏

「蒸馏巴菲特 + 芒格 + 达利欧」：

1. 拆成独立目录并行
2. 各自采集、各自验证
3. 可选再做一个对比 Skill，每条框架标明来源人物
4. 不要先合成再补证据

---

## 6. 部分本地素材 / 一手资料不足

只有 1 本书、几条微博、或网搜 <10 条可用源：

1. 明确告诉用户信息不完整
2. 诚实边界加「已获取 vs 待获取」
3. 模型减到 2–3 个，禁止脑补私生活和细到小时的习惯
4. 给用户一份补料清单（哪类一手最值钱）
5. 仍按七级提取；没有形成故事的信念不写

---

## 7. 更新已有 Skill

1. 旧版改名加版本（`v1`），新建 `v2`
2. 新版本写更新日志：哪些变了、依据哪条新证据
3. 用户说「这不对」时：先要反例或一手料，再改框架，不要为了好听改
4. 复跑保真度评分卡

---

## 8. 保密场景

商业机密、未公开创始人、企业内部方法论：

1. 标「保密」，默认不写进可分享 README
2. 只存本地，引用来源脱敏
3. 用户自负保密责任
4. 不把内部人名写进 description 触发词（避免被无关对话激活）

---

## 9. 跨文化蒸馏

1. 增加文化背景维
2. 识别可能的误读（直接/间接、个人主义/关系、宗教禁忌）
3. 诚实边界写文化局限
4. 能用对象语言的一手源就不要只靠译文

---

## 10. 身边的人（非公开人物）

1. 必须有用户提供的一手观察或聊天，禁止用同名公众人物填空
2. 写清「这是观察者视角，不是本人自述」
3. 默认保密
4. 决策框架只写用户亲眼见过的重复行为
