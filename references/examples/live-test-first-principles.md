## 效果（就这一次）

**方法层是可执行的。** 按 4.5 层 + 七级提取 + 诚实边界写，得到的不是百科词条：五个模型都能回答「何时拿起、拿起来怎么走」，迁移题「必须六轮面试」能推出「轮次只许买独立信号 / 候选人会还手 / 禁止报正确轮次」，而不是复述电池故事。

**采集层在本环境基本无效。** 这是这次实跑最硬的负结果。

1. `python3 scripts/run.py collect` 依赖 `pip install -e scripts/`。`setuptools` 报多个顶层包：`crawl`、`search`、`transcribe`。没有 `uv`。
2. 用 `PYTHONPATH` 绕过安装后，Agent 搜索要 `claude` CLI；没有则降级 DuckDuckGo HTML。六维仍是 0 结果 0 正文。
3. 空采集标 `success: true`，`cli.py` 打印「采集完成」。Agent 若不读 `total_results`，会以为采过。
4. 默认六维是人物模板：`生平`、`Twitter`、`口癖`。对「第一性原理」问生平，即使爬虫活着也问错。
5. `team` 在 0 素材上仍生成空「分析结论」，像有多 Agent，没有分析。

**保真度门后补了一刀。** 构建之后另开答题 Agent（只读产物、不联网）和评分 Agent（不重答）。五题方向与公开传统一致，评分 **90/100 · A**，无崩溃维。单评分员，没有按「两个评分 Agent」复跑。`FIDELITY.md` 已写入。

这只说明：**方法被遵守、材料靠宿主搜索时，思想 Skill 可以跑起来。** 不说明采集脚本可用。空成功仍在。

**和宣传句的差距：** 「强制跑 scripts/run.py」做到了；「六路采集」没有采到东西。成品质量来自宿主搜索 + 构建 Agent 是否遵守方法，不是来自脚本。

## 独立答题在测什么

构建时的自检题是「六轮面试」（写在 `examples/` 里）。独立答题换了五题，其中「报价必须跟行业龙头一样」正文和 examples 都没有。答题按协议把龙头价降成类比、不编数字。评分认为可迁移。

`scripts/run.py decompose` 只会打印检查单，不搜索、不评分。

## 若要让效果接近 SKILL 所写

- 修 `pyproject.toml` 的打包，让 `run.py` 的 pip 路径能装。
- 空结果不要 `success: true`；`total_results == 0` 应失败并写进 `00-sources.md` 提示。
- 给 D3/D4 另做维度，不要拿「生平 / Twitter」套思想。
- 脚本搜不到时，明确要求宿主搜索，不要让 `team` 对着空气写报告。
- 出厂必须另开答题 Agent + 评分 Agent。

本评测不包含上述修复。先看效果，再决定要不要改脚本。
